# Identificando-Atributos-de-Qualidade
Analisar situações do cotidiano e identificar quais atributos de qualidade de software estão envolvidos.

Aplicativo de Banco
a) Só parcialmente. Entrega o requisito funcional, mas o não-funcional
falha. Qualidade não é só funcionar, é performar bem.
b) Adequação Funcional (ok, o PIX foi feito) e Eficiência de Desempenho
(comprometido pelo tempo de resposta alto).

Sistema de Matrícula
a) Usabilidade (erro clássico de UI/UX).
b) Usuário final frustrado e geração de um gargalo absurdo de
chamados no suporte/Help Desk da instituição.

Loja Virtual
a) Confiabilidade (queda de disponibilidade) e Eficiência de
Desempenho (sistema sem escalabilidade para o pico de acessos).
b) Para a empresa significa downtime e prejuízo financeiro na veia; para
o cliente, frustração e migração para o concorrente.

Sistema Hospitalar
a) Manutenibilidade (falta de analisabilidade e documentação, o famoso (código espaguete).
b) Produtividade da dev team fica pífia, aumento no lead time para
correções simples e acúmulo de débito técnico.

App de Delivery
a) Confiabilidade (falta de maturidade na versão gerando crash na
aplicação).
b) Rotina de QA. Dava para evitar com Testes de Regressão e uma
esteira de CI/CD bem configurada antes do deploy em prod.
